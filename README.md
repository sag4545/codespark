# CodeSpark – Upgraded Coding Awareness Platform

## What is included
- Student home/dashboard-style landing page
- Scratch-to-advanced learning path with 30 modules
- Separate Python Lab and JavaScript Lab
- Browser code execution
- Examples, reset, copy and save
- Beginner / Intermediate / Advanced quizzes
- Strong learning-first curriculum structure
- Teacher/Admin dashboard
- Admin lesson creation stored in browser localStorage
- Student progress prototype
- Responsive design for school/student devices

## Run
Keep all files in one folder and open `index.html` in Chrome/Edge.

## Important
The Admin dashboard is a functional front-end prototype. For real multi-student deployment, connect the admin actions and student progress to Firebase, Supabase, or a Flask backend/database.
Python execution uses Skulpt from a CDN, so internet access is required for Python execution.
